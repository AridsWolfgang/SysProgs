## Story — What `call` Actually Does

```asm
; caller
call foo        ; pushes RIP (8B) → rsp-=8, [rsp]=ret addr, jmp foo

; foo prologue
push rbp        ; save caller's frame
mov rbp, rsp    ; new frame base
sub rsp, 16     ; locals: 2×8B, keep 16B align before next call
mov [rbp-8], rdi ; spill arg maybe
; ... body ...
add rsp, 16
pop rbp
ret             ; pops RIP → jmp back
```

*High addr at top, low at bottom, `rsp` grows down.* `rbp` is the bookmark debuggers use for backtrace (`bt` walks `saved rbp` chain).

**Alignment:** x64/A64/RISC-V require `rsp % 16 == 0` before `call`. `sub rsp, 8` without care → `movaps` in callee faults (`#GP`). Always `sub` multiples of 16.

**Red zone (SysV leaf only):** 128B *below* `rsp` safe without `sub` — leaf function (no `call`) can use `[rsp-8]` directly. Win64 has **shadow space** 32B *above* ret for callee to spill `rcx/rdx/r8/r9` — even if you don't use it, you must reserve.

## Callee vs Caller — Who Saves?

| ABI | Callee (must preserve) | Caller (can clobber) |
|-----|------------------------|----------------------|
| SysV AMD64 | rbx rbp r12-r15 | rax rcx rdx rsi rdi r8-11, xmm0-15 |
| Win64 | rbx rbp rsi rdi r12-r15 | rax rcx rdx r8-11 |
| AAPCS64 | x19-x28, sp | x0-x18, v0-v31 |
| RISC-V | s0-s11 (x8-x9,x18-x27) | t0-t6, a0-a7 |

> **Break it:** Write `foo` that `mov rbx, 42` without `push rbx` → caller’s `rbx` corrupted → crash later, not here. Fix with `push rbx`/`pop rbx`. That's callee-saved.

## Try — objdump Is Truth

```bash
gcc -O0 -S your.c -o your.s && cat your.s
# look for: push rbp; mov rbp,rsp; sub rsp, N

gcc your.c -o your && objdump -d your | less
# look for: 55 push rbp; 48 89 e5 mov rbp,rsp; 48 83 ec 10 sub rsp,0x10

# 7th arg spill
long foo(long a,b,c,d,e,f,g){return a+b+c+d+e+f+g;}
gcc -S -O0 foo.c -o foo.s && grep -A2 "mov.*\[rsp" foo.s
# g at [rsp+8] (SysV) — on Win64, [rsp+40] (shadow+stack)
```
