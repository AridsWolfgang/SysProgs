Principles

Intentional, not decorative

Content first. 68–76ch prose, 16px/1.7. One token file drives web + future mobile. No hard-coded colors. Dark-first (#0B1220), light equally considered (#F7F8FA). 4pt grid, 4.5:1 contrast, focus rings, reduced-motion.

Layout

Rules

  • New color → token in tokens.css + light variant, never hard-coded.
  • New spacing → var(--space-*).
  • New component → components.css + demo here.
  • Check contrast ≥4.5:1, focus ring, reduced-motion, keyboard /.
  • Lesson blocks typed: prose, callout, image, video, code, resource, quiz, lab — never markdown dump.
